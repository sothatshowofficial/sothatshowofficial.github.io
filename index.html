Three common worries

1 · "I've never done 3D."

That's fine. You don't need to.

You tell Claude what you want in normal words, the way you'd text a friend. Claude writes the code that builds the scene. You watch the preview and say what to change.

  • Ready-to-copy messages for every step, and example chats so you can see what to type.
  • Weak notes next to strong notes, so Claude gets your changes right sooner (page 35).
  • A prompt library for the parts where people get stuck.

2 · "AI videos look cheap."

Most do. The guide shows you why, and how to fix it.

Most AI videos look cheap for the same few reasons: the camera moves around for no reason, the model looks fake, and the first second is boring. The guide names each problem and gives you the fix.

  • The 1-second test: if a stranger can't name the object in one second, they scroll away (page 26).
  • 12 common problems, each with a fix (pages 31–33).
  • A checklist prompt, so Claude reviews its own reel before you watch it. Without one, it grades itself too kindly (page 34).
